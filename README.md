An interactive, luxury web showcase presenting an AI-powered WhatsApp concierge agent for a high-end Saudi Arabian hotel. Designed with Saudi hospitality etiquette (*Karam* & *Diyafa*), bilingual intelligence (Arabic default, English on demand), real-time room quotation calculator with 15% Saudi VAT, and an interactive 3D Titanium iPhone 16 Pro WhatsApp simulator.

---

## ✨ Key Highlights

- **📱 Interactive 3D Titanium iPhone 16 Pro Simulator:**
  - True-to-life WhatsApp Dark Mode interface.
  - Interactive chat with **Sultan (سلطان)**, the Senior AI Guest Concierge.
  - Real-time typing indicators, audio sound effects (Web Audio API synthesized WhatsApp pop & chime sounds), and quick prompt buttons.
  - Live Saudi room price quotations with breakdowns (SAR room rate + 15% VAT).
- **🇸🇦 Authentic Saudi Hospitality:**
  - Speaks authentic Saudi Arabic by default (*"أهلاً وسهلاً بك في فندق قصر الرياض الملكي"*).
  - Seamless instant toggle or dynamic language detection for English.
- **🏨 Interactive Luxury Suites Catalog:**
  - **Royal Penthouse Suite (جناح البنتهاوس الملكي)** — 4,200 SAR/night
  - **Executive Diplomatic Suite (الجناح الدبلوماسي التنفيذي)** — 2,100 SAR/night
  - **Najdi Heritage Deluxe (غرفة ديلوكس التراث النجدي)** — 1,250 SAR/night
  - Click any suite card to automatically inject booking inquiries directly into the iPhone simulator.
- **⚡ n8n + Evolution API Architecture:**
  - Includes ready-to-import production n8n workflow (`saudi_hotel_whatsapp_ai_concierge_workflow.json`).
  - Connects WhatsApp webhook (Evolution API v2) to OpenAI GPT-4o with luxury hospitality system instructions and automated quotation parsing.
